# Gf Mod для Super Battle Golf

Мод добавляет настройки игрового процесса, HUD, выдачу предметов, управление погодой для хоста и меню с настраиваемыми клавишами.

## Установка

### Через установщик — рекомендуется

1. Закройте Super Battle Golf и Steam.
2. Запустите `gfModInstaller.exe` из архива или папки `Release`.
3. Укажите папку игры:

   ```text
   D:\games\steam\steamapps\common\Super Battle Golf
   ```

4. Дождитесь сообщения об успешной установке и запустите игру через Steam.

Установщик сам добавит BepInEx 5, если его ещё нет, и положит мод в `BepInEx\plugins\gfMod.dll`.

### Вручную

1. Установите [BepInEx 5 для Unity/Mono x64](https://github.com/BepInEx/BepInEx/releases) в корневую папку Super Battle Golf.
2. Один раз запустите игру и закройте её — BepInEx создаст нужные папки.
3. Скопируйте `gfMod.dll` в:

   ```text
   Super Battle Golf\BepInEx\plugins\gfMod.dll
   ```

4. Запустите игру.

## Как пользоваться

Нажмите клавишу <kbd>`</kbd> (обратная кавычка, обычно под `Esc`) для открытия меню Gf Mod. Нажмите её повторно или `Esc`, чтобы закрыть меню.

В верхней части меню находятся разделы:

- **Features** — Assist, защита от льда, ветра, сопротивления воздуха, отбрасывания и другие игровые функции.
- **Keybinds** — назначение клавиш. Нажмите на бейдж текущей клавиши, затем нажмите новую клавишу.
- **HUD** — включение и отключение элементов интерфейса мода.
- **Credits** — выбор количества и выдача кредитов.
- **Items** — выдача предметов. Для большинства предметов хост лобби также должен использовать Gf Mod; Coffee может работать через обычный игровой диспенсер.
- **Weather** — погода для хоста лобби: выбор события, запуск и автоматическая погода.

Все изменения, сделанные в меню, сохраняются автоматически.

## Клавиши по умолчанию

| Клавиша | Действие |
| --- | --- |
| `F1` | Assist |
| `F2` | Coffee Boost |
| `F3` | Режим ближайшего мяча |
| `F4` | Разблокировать косметику |
| `F5` | Меню предметов |
| `F6` | Показать/скрыть HUD мода |
| `F7` | Случайный предмет из ящика |
| `F8` | Защита от льда |
| `` ` `` | Меню Gf Mod |
| `F9` | Без ветра |
| `F10` | Без сопротивления воздуха |
| `F11` | Множитель скорости |
| `F12` | Бесконечное использование предметов |
| `F13` | Без отбрасывания |
| `F14` | Защита от мин |

Клавиши можно изменить в разделе **Keybinds**. После открытия меню предметов используйте клавиши, отображаемые рядом с предметами, чтобы выдать нужный.

## Настройки вручную

Файл настроек создаётся после первого запуска игры:

```text
Super Battle Golf\Mods\gfMod.cfg
```

Закройте игру перед редактированием файла. Там можно задать клавиши, множитель скорости, отображение HUD и параметры следа мяча. После изменения визуальных настроек перезапустите игру.

## Если мод не загрузился

1. Убедитесь, что файл находится именно в `BepInEx\plugins\gfMod.dll`.
2. Убедитесь, что игра полностью закрыта перед установкой или обновлением.
3. Посмотрите журнал `BepInEx\LogOutput.log` в папке игры.
4. При обновлении замените старый `gfMod.dll` новым файлом.

## Сборка из исходников

В командной строке из корневой папки проекта:

```bat
compile_mod.bat "D:\games\steam\steamapps\common\Super Battle Golf"
```

Скрипт соберёт мод и сразу скопирует его в папку плагинов игры.
